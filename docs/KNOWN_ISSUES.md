# Known Issues

这里只记录尚未解决、需要实机确认或属于明确产品限制的事项。已修复问题应删除，而不是长期保留历史流水账。

## 需要实机持续验证

### 动态聊天中的整层摘录

- SillyTavern 会在切换聊天和重新渲染消息时替换 DOM。
- 2.0.5 已使用稳定根节点观察、`CHAT_CHANGED` 刷新和事件委托处理，但不同 SillyTavern 主题或第三方扩展仍可能改变消息操作区结构。
- 涉及 `capture-view.js`、消息选择器或按钮样式时，必须实测：切换多个聊天、重新生成消息、编辑消息、桌面与移动端。

### 更新时存在本地修改

- SillyTavern 的扩展更新由 Git 工作树状态决定。
- 用户手动修改安装目录后，一键更新可能失败并显示服务器错误。
- 当前更新功能不会覆盖或删除用户的本地代码修改；需要用户先恢复干净安装或重新安装。

### 字体与图片导出

- 网络字体受字体站点可用性、CORS、浏览器缓存和加载时机影响。
- 较大的本地字体可能只能在当前页面会话中使用。
- 分享长图、网络字体和移动端下载必须用真实浏览器验证。

## 产品限制

### 需要 SillyTavern 1.12.0 或更新

- 文件存储依赖 SillyTavern 1.12.0 引入的用户文件接口（`/api/files/*`、`data/<user>/user/files`）。更老的版本无法保存笔记。

### 文件接口没有列目录和原子多文件写入

- 酒馆没有列出文件的接口，所以由 `tavern-notes__manifest.json` 记录所有分片和备份。
- 一次改动可能写多个文件（分片、manifest）；写入顺序是先分片后 manifest，中途失败时以 manifest 为准，重复写入会覆盖。
- 两台设备同时改同一个月份的笔记时，后写的一方会先重读 manifest 再合并，但极短时间内的并发仍可能丢一边的改动。

### 本地字体不跨设备

- 分享卡导入的本地字体存在浏览器 IndexedDB，换设备需要重新导入。

### 旧后端只能手动删除

- 酒馆没有删除 Server Plugin 的接口。迁移后只能提示用户自己删 `plugins/tavern-notes`。
