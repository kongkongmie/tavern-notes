# 酒馆笔记 3.0 新用户安装指南

3.0 起酒馆笔记只有一个版本，只要装一个扩展，不需要后端、安装器，也不用重启酒馆。

## 准备

- SillyTavern 1.12.0 或更新版本（2024 年中以后的版本都可以）。
- 能打开 SillyTavern 的浏览器，电脑和手机都行。

## 安装

1. 打开 SillyTavern，点顶部的「扩展」图标（积木形状）。
2. 点「安装扩展 / Install extension」。
3. 粘贴下面的地址，点安装：

```text
https://github.com/kongkongmie/tavern-notes
```

4. 看到安装成功后，刷新页面。

## 确认装好了

- 聊天页的输入栏附近会出现酒馆笔记的按钮（书本图标），也可以在扩展菜单里点「酒馆笔记」。
- 打开面板，底部显示「文件模式 · 已连接」就说明一切正常。
- 发一条消息，它会出现在「User 输入」里；选中聊天里的一段文字，点「摘录选中」，它会出现在「摘抄」里。

## 以后怎么更新

- 酒馆的扩展面板会提示更新，点更新即可。
- 酒馆笔记自己也会检查新版本，在「更多 → 版本与更新」里可以一键更新。

## 笔记存在哪里

```text
SillyTavern/data/<用户>/user/files/tavern-notes__*.json
```

同一个酒馆，电脑和手机看到的是同一份笔记。每天第一次改动时会自动备份一份，保留最近 7 份，可在「更多 → 自动备份」里恢复。想自己留一份，也可以用「导入导出笔记」导出 JSON。

## 用过旧版（2.x）

更新后刷新页面，酒馆笔记会自动发现旧笔记并问你要不要搬过来，点「确定」就好。详细说明见 [README](../README.md) 的「从 2.x 升级」。
