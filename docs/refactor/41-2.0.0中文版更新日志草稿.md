## 这是一次什么更新？

Tavern Notes 2.0.0 是一次完整的统一版升级。

从这个版本开始，新用户只需要安装一次 `tavern-notes`，首次打开时即可选择：

- **Full 文件模式**：笔记保存到 SillyTavern 用户数据目录，支持 Server Plugin、自动备份和完整文件能力。
- **Lite 浏览器模式**：笔记保存到当前浏览器的 IndexedDB，无需安装 Server Plugin，适合手机和受限环境。

两种模式现在共用同一套界面、摘录工具、标签、搜索、编辑、分享卡、主题和更新中心。Full 仍是公共源码的维护本体；独立 `tavern-notes-lite` 仓库只作为旧 Lite 用户的兼容更新和应急安装入口。

> Full 与 Lite 的笔记数据仍然彼此独立。切换模式不会迁移、合并或删除笔记；需要迁移时请使用 JSON 导出和导入。

## 主要更新

### 1. Full / Lite 二合一

- 新增首次启动的 Full / Lite 模式选择页。
- 标题区域会显示当前存储模式，并可以随时重新选择。
- 同一套前端会根据当前模式自动连接 Full Server Plugin 或 Lite IndexedDB。
- 保留原 Full 数据目录、备份位置、Server Plugin API、仓库地址和更新路径。
- 保留原 Lite IndexedDB、Lite 主题、字体记录和已有笔记，不重写旧数据。
- Lite 模式会自动隐藏“打开主题文件夹”等仅 Full 可用的功能。
- 原独立 Lite 仓库继续为旧用户提供兼容更新，但新用户无需同时安装两个扩展。

### 2. 笔记、标签与角色整理

- 新增手动创建 User 灵感笔记。
- 支持直接编辑笔记正文和标签。
- 新增标签架、标签搜索、标签筛选和标签管理器。
- 支持全局重命名或删除标签；删除标签不会删除笔记。
- 删除某个标签下的最后一条笔记后，最近使用的空标签仍会保留，方便继续使用。
- 支持按全部笔记、角色、User 输入、摘录和标签浏览。
- User 输入会统一聚合到一张 User 卡，不再因不同角色卡生成多个 User 角色。
- User 卡可以汇总不同角色聊天中产生的所有 User 输入。
- 笔记卡片重新排版，正文预览空间更大；点击卡片可以查看全文并使用复制、重新输入、分享、编辑和删除功能。

### 3. User 输入记录与整理

- 新增“自动记录 User 输入”开关。
- 开关切换后会显示明确的成功提示。
- 关闭记录只会停止之后的自动记录，不再隐藏或删除已经保存的 User 输入。
- 新增连续重复 User 输入自动合并，并保留重复次数。
- 新增精确匹配和前缀匹配忽略规则，可排除固定 Quick Reply 指令。
- 新增历史重复输入扫描、预览和确认清理流程。
- 清理只会处理预览中确认的内容，并保留后续编辑所需的重复信息。

### 4. 摘录工具

- 新增选中文字后的浮动摘录按钮。
- 支持普通文本、渲染后的 HTML 内容、输入框文字和嵌入页面中的选区。
- 新增“整层摘录”，可以直接保存一整条消息。
- 整层摘录支持自定义正文标签，默认识别 `content`。
- 新增排除标签设置，可以在摘录前移除思维链、摘要或其他不需要的标签内容。
- 支持从酒馆原始消息中恢复被折叠的长正文，不再只摘到“正文（8000+字）”等折叠摘要。
- 同一条消息包含多个正文标签时，会按照原顺序合并。
- 扩大消息节点识别范围，兼容无 `mesid`、延迟挂载、聊天容器替换和批量插入的消息。
- 防止同一条消息中的相同摘录因空白差异被重复保存。
- 单条笔记最大长度由 20,000 提升到 200,000 字符。

### 5. 导入、导出与备份

- Full 和 Lite 都可以导出 JSON 备份和 TXT 阅读文件。
- 新增 JSON 备份导入，可在 Full 与 Lite 之间手动迁移笔记。
- 导入会检测重复内容，大型备份会分批处理。
- 编辑后的正文、标签和重复次数会保留在导入、导出、搜索、统计和角色视图中。
- Full 模式新增笔记变更后的本地每日自动备份。
- 安装器和导入流程不会主动删除已有笔记。

### 6. 分享卡与字体

- 重做日历、对话、墨白和简书四种分享卡排版。
- 角色名和日期开关现在会在全部版式中正确生效。
- 关闭标题信息后，正文会自动使用空出的区域。
- 新增自定义背景色和文字色，同时保留内置背景色板。
- 优化字体大小控制和多主题下的分享卡面板。
- 支持导入网络字体地址、完整 `@import` 代码和本地字体文件。
- 网络字体会按实际笔记文字加载对应字符分片，再生成 Canvas 图片。
- 修复字体导入成功但预览仍使用系统回退字体的问题。
- 网络字体设置只保存轻量地址，不再把整份远程 CSS 重复写入浏览器设置。
- 旧的大型字体记录会自动压缩，避免触发浏览器存储容量上限。
- 导入或切换字体后，字体库和分享卡预览会立即刷新。

### 7. 界面与移动端体验

- 顶部操作区改为统一图标按钮，并会根据面板宽度自动调整或收进“更多”菜单。
- 主题、语言、启动方式和关闭按钮集中到右上角工具区。
- 移动端向下阅读笔记时，顶部工具栏会平滑收起，为正文提供更多空间。
- 折叠后会保留关闭按钮和醒目的“展开工具栏”胶囊按钮；点击顶部区域即可自然展开。
- 修复筛选后笔记较少时滚动闪烁、页面反复折叠或无法退出阅读状态的问题。
- 修复移动端视口漂移、顶部按钮越界和输入栏按钮挤压问题。
- 新增可拖动的悬浮球入口，并支持重置位置。
- 默认图标改为适配浅色和深色背景的高对比资源。
- 完成简体中文、繁体中文、英文和韩文的主要界面与状态提示。

### 8. 主题系统

- 重构 Full / Lite 共用主题运行时。
- 新增默认主题日夜切换和 Twilight Blue 夜间样式。
- 新增 Apple Glass，并修复其预览隔离问题。
- 暂时移除问题较多的 Secret Files 内置主题，避免旧选择继续覆盖界面。
- 修复融合浅色酒馆主题时背景采样失败的问题。
- 插件根字号固定，不再被酒馆美化主题的全局字号缩放带走。
- 优化默认主题阴影、卡片层次、浮层、编辑器和不同屏幕宽度下的布局。

### 9. 安装与更新

- 从 `1.0.2` 起提供 Windows、Android Termux、Linux、macOS 和云服务器安装方式。
- 支持 SillyTavern 内置 Git 扩展安装器，之后可以直接检查更新。
- 新增 Windows 单文件联网安装器、Shell 在线安装命令和完整离线包。
- 安装器会备份旧插件文件与 `config.yaml`，并启用 `enableServerPlugins`。
- 新增内置版本提醒和“版本与更新”页面。
- 更新中心可以同时显示默认更新日志和作者维护的中文补充说明。

## 升级说明

### 新用户

在 SillyTavern 的“安装扩展 / Install extension”中粘贴：

```text
https://github.com/kongkongmie/tavern-notes
```

安装完成后，在首次启动页面选择 Full 或 Lite。

### 现有 Full 用户

2.0.0 包含前端和 Server Plugin 的累计更新。更新扩展后请：

1. 重新运行：

   ```text
   SillyTavern/public/scripts/extensions/third-party/tavern-notes/install-server-plugin.bat
   ```

2. 完整重启 SillyTavern。
3. 刷新浏览器页面后再开始测试。

### 现有 Lite 用户

- 使用统一版 Lite 模式：更新 `tavern-notes` 后刷新页面即可。
- 仍在使用独立 `tavern-notes-lite`：可以继续接收兼容更新，也可以安装统一版后选择 Lite 模式。
- 两个扩展不要同时启用，以免出现重复入口或重复监听。

## 数据兼容说明

- 2.0.0 不修改现有 Full 笔记文件格式。
- 2.0.0 不修改现有 Lite IndexedDB 名称。
- 切换 Full / Lite 不会自动移动、合并或删除数据。
- 建议重大更新前分别导出 Full 与 Lite 的 JSON 备份。
