# 分享卡保存位置
> 更新于 2026-08-25 · 状态：等待本地实机验收

## 目标
让桌面浏览器导出分享卡时显示系统“另存为”窗口，用户可以明确选择目录；手机和不支持该能力的浏览器继续使用系统下载。

## 允许修改
- `features/share-card-controller.js`
- `index.js` 中分享卡下载接线
- `tests/share-card-note-detail-feature.mjs`

## 不在范围
- 主题、美化和样式文件
- 固定绝对路径配置
- 版本号、提交和推送

## 验收
- [ ] 支持的桌面浏览器在生成图片前弹出“另存为”（待实机）
- [x] 取消保存不会生成图片、下载文件或弹出成功提示
- [x] 手机和不支持的浏览器仍能使用原下载链路
- [x] 普通分享卡与全文长图文件名正确
- [x] 自动测试通过并同步本地安装
