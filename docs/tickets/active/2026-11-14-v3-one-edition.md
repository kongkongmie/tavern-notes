# Ticket: 3.0.0 只保留一个版本

- 状态：等待本地验收
- 创建日期：2026-11-14
- 目标版本：v3.0.0
- 发布权限：仅本地（用户说「推」之后才提交、推送主仓库和 tavern-notes-lite）

## 目标

删掉 Full / Lite / 后端，只保留文件存储一个版本，推给所有用户；旧用户升级时自动、安全地把数据搬过来。

## 做了什么

- 删除：存储模式选择与切换、Full 专用仓库、模式路由、两版共存逻辑、`server-plugin/`、全部安装器、对应测试与文案、主题文件夹按钮。
- 合并：笔记 / 标签 / 输入清理 / 字体 / 状态仓库各剩一份，`liteApi` 更名 `notesApi`。
- 迁移：`repositories/legacy-sources.js` 只读旧后端与旧 IndexedDB；迁移完成后提示可删 `plugins/tavern-notes`；导入支持 2.x 每日备份格式。
- 独立 Lite 仓库最终版 1.0.0：一键安装主扩展、删除自己、刷新。
- 版本 3.0.0，README、安装指南、CHANGELOG.md、设计与状态文档同步。

## 明确不做

- 不改文件存储的数据格式（2.x 迁移过来的文件保持可用）。
- 不写 CHANGELOG.zh-CN.md 的作者注释。
- 不提交、不推送。

## 验收条件

- [ ] 新装：只粘贴仓库地址就能用，无任何模式选择或后端提示。
- [ ] 2.x Full 用户更新后：提示迁移 → 核对通过 → 提示可删后端。
- [ ] 2.x Lite 模式 / 独立 Lite 用户：笔记与主题被搬过来；独立 Lite 一键升级成功。
- [ ] 删掉后端后，导入 `tavern-notes-daily-backup.json` 成功。
- [ ] 电脑（Pake）与手机实测通过。

## 必须运行的测试

- `node --test tests/*.mjs`
- `git diff --check`
